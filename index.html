PWN 脚本工作台

从函数和输入条件出发，写好每一段链。

写 PWN 的 exp 时，查系统调用号、记参数顺序和走哪个寄存器、拼 shellcraft 调用链、拼 ROP 链，都要翻 man、翻表、翻笔记。这个页面把这些事收到一处：选架构 → 搜调用 → 按提示填参数 → 生成能粘进 exp 的 pwntools 代码骨架，填实参数、回 VM 对真题跑通才算数，seccomp 白名单检查和 ROP 链模板也在同一页。

在附件目录运行仓库中的 Python 工具，把输出粘贴到这里。只读取 ELF，不启动题目。

按目标函数入口的实际栈相位选择，不把补 ret 当作通用修复。SROP 不使用这两个选项。

生成的 ROP 链
PYTHON / PWNTOOLS

    

    

    

    
地址查找与单 pop 替代
    
地址从哪来：gadget 用 ROPgadget --binary ./prog | grep "pop eax" 或 ropper 找；offset 用 cyclic 试出来；BSS 看 readelf -S ./prog 的 .bss（要可写、够放 8 字节）。

    
没有 pop3 只有单个 pop 的回退：别硬套模板，拆成单个 pop 逐个设寄存器。i386 read(0, bss, len)：pop eax;ret→3、pop ebx;ret→0、pop ecx;ret→bss、pop edx;ret→len，再 int 0x80；execve(bss, 0, 0)：pop eax;ret→11、pop ebx;ret→bss、pop ecx;ret→0、pop edx;ret→0，再 int 0x80。amd64 read(0, bss, len)：pop rax;ret→0、pop rdi;ret→0、pop rsi;ret→bss、pop rdx;ret→len，再 syscall；execve(bss, 0, 0)：pop rax;ret→59、pop rdi;ret→bss、pop rsi;ret→0、pop rdx;ret→0，再 syscall。单个 pop gadget 用 ROPgadget 按寄存器名分别找：ROPgadget --binary ./prog | grep "pop rax"、ROPgadget --binary ./prog | grep "pop rdi"、ROPgadget --binary ./prog | grep "pop rsi"、ROPgadget --binary ./prog | grep "pop rdx"。

    

    
运行前核对
      
  • offset 用 cyclic 实测；gadget 地址与可写内存以当前 ELF 为准。
  • 核对 gadget 弹栈顺序、字符串结尾 NUL 和目标输入的终止条件。
  • 两阶段发送按目标协议同步，sleep 不能保证读入边界。
  • 模板与示例地址未经实际题目运行验证（STATIC_ONLY），请在目标环境中调试，回 VM 对真题跑通才算数。

常量速查
07 / REFERENCE

    
先选中参数输入框，再点击需要的常量。

    

      
文件描述符 fd（固定约定）

        
0stdin 标准输入

        
1stdout 标准输出

        
2stderr 标准错误

        
'rax'上一步 open 的返回值（通常 ≥3）

        
-100AT_FDCWD，openat 用当前目录

      

      
mmap prot（保护位，可相加）

        
0PROT_NONE

        
1PROT_READ

        
2PROT_WRITE

        
4PROT_EXEC

        
7RWX = 1+2+4

        
3RW = 1+2

      

      
mmap flags

        
1MAP_SHARED

        
2MAP_PRIVATE

        
0x20MAP_ANONYMOUS 匿名（fd 填 -1）

        
0x22PRIVATE | ANONYMOUS

        
0x10MAP_FIXED

      

      
open flags

        
0O_RDONLY 只读

        
1O_WRONLY 只写

        
2O_RDWR 读写

        
0x40O_CREAT 不存在就创建

        
0x400O_APPEND 追加

      

      
文件权限 mode（八进制，chmod / mkdir / creat / open 带 O_CREAT 时用）

        
0o777rwxrwxrwx 全开，改 flag 权限最常用

        
0o755rwxr-xr-x，可执行文件 / 目录

        
0o644rw-r--r--，普通文件

        
0o600rw-------，只有自己能读写

        
0o400r--------，只读

      
每位 = 读 4 + 写 2 + 执行 1，三位依次是属主 / 组 / 其他。必须带 0o 前缀：写成十进制 777 是另一组权限位。

      
常用长度 / 哨兵

        
0x100256 字节

        
0x10004096，一页

        
0addr/offset：让内核选 / 从头

        
-1匿名 mmap 的 fd

        
'rsp'栈顶地址，常作 buf

        
'rax'上一步返回值，最常用
